# 活動量と体格に基づく食事目標

新規登録②・プロフィール変更で普段の活動量を三択（座って過ごすことが多い／日常的に適度に動く／立ち仕事や運動でよく動く）から選ぶ。既存ユーザーはmoderateで引き継ぐ。登録時は選択必須。

新規登録④と目標未登録時の設定では、画面を開くとPOST /api/v1/goal/nutrition_suggestionを呼び出し、AI提案を自動入力する。専用のAI算出ボタンは表示しない。入力情報が変わらないままステップを往復した場合は再算出しない。保存失敗後の下書きと目標変更での保存済みの値は保持し、目標変更では「入力情報から出し直す」を押した場合だけAI提案で置き換える。算出中は栄養値の編集を止め、完了後は利用者が自由に修正できる。保存するまで現在の目標は変更されない。

## 計算・検証

19〜78歳はMifflin-St Jeor式の安静時エネルギー推定（体重kg、身長cm、満年齢）を用いる。男性は10×体重 + 6.25×身長 - 5×年齢 + 5、女性は最後の定数が-161。普段の活動量の係数1.5／1.75／2.0を掛け、10kcal単位に丸める。75歳以上の係数は低い1.45・ふつう1.7、高いを選んでも1.7まで。これは維持エネルギーを出すアプリ上の推定方法で、個人の必要量を実測するものではない。

- 原著: https://pubmed.ncbi.nlm.nih.gov/2305711/
- 身体活動レベル: https://kennet.mhlw.go.jp/information/information/food/e-02-001
- 栄養バランス: https://www.mhlw.go.jp/stf/newpage_44138.html

初期のPFC比率は17.5%／25%／57.5%。19〜78歳以外や一般向けの自動計算範囲（算出結果1000〜5000kcal）を外れる場合はAI提案を行わず、年齢別の食事摂取基準を表示し、その旨を画面で説明する。この範囲は計算サービスの対象範囲であり、万人の摂取量の上下限を示すものではない。

AIは基準計算の90〜110%以内のカロリーとPFC比率を提案する。たんぱく質は13〜20%（50〜64歳は14〜20%、65歳以上は15〜20%）、脂質20〜30%、炭水化物50〜65%の範囲をサーバーでも検証する。gはたんぱく質・炭水化物4kcal/g、脂質9kcal/gから計算する。減量・増量・治療を目的とする目標は生成しない。境界や係数の適用は研究式・国内基準を組み合わせたアプリ上の実装方針。

## API・通信

年齢・性別・身長・体重・活動量・活動係数と計算式のカロリーを送る。生年月日そのもの・氏名・メール・パスワードは送信しない。store:falseでResponses APIに構造化出力を要求する。OPENAI_API_KEYは既存の写真解析と同じものを利用し、必要ならOPENAI_NUTRITION_MODELでモデルを指定する（既定gpt-5.4-mini）。

APIキー未設定、タイムアウト、不正な出力、基準範囲外の提案では、登録を止めず計算式の値へ戻し、画面に通知する。同一入力の有効なAI提案は6時間キャッシュし、接続元ごとに15秒以内の異なる入力による呼び出しを抑える。キャッシュキーは入力のハッシュで、NullStore環境ではプロセス内のMemoryStoreを使う。複数ワーカー間で制限を共有する場合は共有キャッシュを設定する。

GET /api/v1/goal/nutrition_defaultsはAIを呼ばない。登録前はbirthdate・gender・height_cm・weight_kg・activity_levelを渡し、ログイン中で引数がなければ本人のプロフィールを使う。古いクライアントから年齢・性別だけで呼ぶ場合は従来の基準表を返す。
